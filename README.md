# Практическая работа 45 DevOps

Статическая витрина «Сигнал»: HTML, CSS, JavaScript и оригинальные SVG-иллюстрации. Работы на странице — учебные концепты.

## Проверка

Workflow: `.github/workflows/main.yml`. При push или Pull Request в main проверяются `index.html`, `style.css`, `script.js`. Также предусмотрен ручной запуск. Используется актуальный `actions/checkout@v7`; назначение соответствует примеру checkout@v4 из лекции.

Результат находится во вкладке Actions. Успешный запуск подтверждает наличие файлов, но не заменяет проверку синтаксиса и поведения сайта.

## Повторить эксперимент

Временно переименовать `script.js`, сохранить изменение коммитом и выполнить push. Проверка должна завершиться ошибкой. После возвращения исходного имени снова выполнить commit и push — проверка должна пройти.

## Открыть сайт локально

Открыть `index.html` в браузере. В галерее работают фильтры, на узком экране — раскрываемое меню. Ссылки используют относительные пути, поэтому проект совместим с GitHub Pages в подпапке репозитория.
