# Ответы по лекции 45 DevOps

1. **Что такое автоматизированный процесс CI/CD?** Последовательность проверок, подготовки и публикации, выполняемая по настроенным правилам.

2. **Из каких компонентов он состоит?** Репозиторий, событие запуска, workflow, jobs, steps, среда выполнения и результаты.

3. **Зачем нужен удалённый репозиторий?** Он хранит исходный код и события, по которым запускается автоматизация.

4. **Что такое Trigger?** Событие запуска: push, pull_request или ручной workflow_dispatch.

5. **Что такое Workflow?** Описанный в YAML рабочий процесс GitHub Actions.

6. **Чем Job отличается от Step?** Job — отдельное задание; Step — одно действие внутри него. Здесь check-project содержит checkout и три проверки.

7. **Зачем нужен YAML-файл?** Он задаёт события запуска, среду, задания и команды.

8. **Где лежат файлы GitHub Actions?** В .github/workflows в корне репозитория.

9. **Что задаёт runs-on?** Среду runner, где выполняется job; в работе ubuntu-latest.

10. **Для чего нужны uses и run?** uses подключает готовое action, run выполняет команды.

11. **Что происходит при ошибке проверки?** Шаг и задание получают failure; последующие обычные шаги задания обычно пропускаются.

12. **Какие преимущества даёт автоматизация?** Одинаковые повторяемые проверки, раннее обнаружение ошибок и меньше ручных операций.
